## About Cacheer Monitor

Cacheer Monitor is a local dashboard for [CacheerPHP](https://github.com/CacheerPHP/CacheerPHP).
Follow cache activity as your application runs and investigate misses, slow
operations, and backend failures.

- [Live metrics, charts, and event history](https://cacheerphp.com/docs/v6/en/cacheer-monitor/).
- [Key inspection, cache lifecycle, and failover analysis](https://cacheerphp.com/docs/v6/en/cacheer-monitor/workflows/).
- [Value previews and JSON/CSV exports](https://cacheerphp.com/docs/v6/en/cacheer-monitor/api/).
