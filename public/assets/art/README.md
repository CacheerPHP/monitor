# Cacheer Monitor artwork

The Monitor mark pairs Cacheer's open C with a continuous signal. The frame
connects it to CacheerPHP; the signal identifies its observability role.

- `logo.svg` and `logo-mark.svg`: light artwork for dark backgrounds.
- `logo-light.svg` and `logo-mark-light.svg`: dark artwork for light backgrounds.
- `logo-mono.svg` and `logo-mark-mono.svg`: single-color versions.
- `favicon.svg`: compact icon on an ink background.
- `icons.svg`: the dashboard's shared interface symbol set.

Keep the artwork's proportions and leave space around the mark. The primary
colors are Cacheer blue (`#315dc9` / `#9ab8ff`), signal teal (`#147c68` /
`#7cd6bd`), and ink (`#182638`). Use the mark without the wordmark in compact
contexts. Interface colors and contrast adjustments live in `../css/style.css`.
